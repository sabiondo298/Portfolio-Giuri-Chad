# Mi Portfolio

Desarrollé este portfolio personal estático con HTML, CSS y JavaScript. En la página presento mi perfil, mis proyectos y mis medios de contacto, utilizando una composición inspirada en los croquis y recursos visuales del proyecto.

## Características

- Incluí una navbar fija con icono de inicio y enlaces a las solapas `Myself`, `Projects` y `Contact`.
- Usé `fotini.png` para crear el diseño ornamental de la navbar, con ramas y flores doradas.
- Agregué mi retrato mediante `pancho123.png`.
- Incorporé animaciones de entrada: mi perfil aparece desde la izquierda y los bloques desde la derecha.
- Creé una solapa `Myself` expandible con información sobre mí.
- Creé una solapa `Projects` expandible con cards para:
  - `Save Obama Gmae`, usando `save-him.png`.
  - `Slither Juan`, usando `slither-bro.png`.
- Enlacé cada card de proyecto con su respectivo repositorio de GitHub.
- Incorporé una solapa `Contact` expandible hacia arriba con enlaces a Instagram, GitHub y LinkedIn.
- Agregué mi dirección de correo dentro de la solapa de contacto.
- Añadí un modo claro con una paleta de colores fríos y guardé la selección en `localStorage`.
- Incorporé un footer oscuro con línea superior dorada y derechos reservados.
- Adapté el diseño para pantallas pequeñas.
